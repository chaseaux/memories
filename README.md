# Memories

Personal collection by chaseaux.

A static gallery of films, music, art, and original notes. This site displays a saved Notion snapshot; changes in Notion are not synchronized automatically.

## Publishing

GitHub Pages serves the root of the `main` branch. Push changes to `main` to update the site. No build step or API credentials are required.
